What data leaves your machine?
  • OpenAlex receives only reference titles and DOIs — never the paper's prose, the student's name, or any body text.
  • The configured LLM provider () receives the document text (needed to locate the reference list and citing sentences) and, for the misquote check, the citation snippets plus OpenAlex abstracts — nothing more. Requests run under the site owner's API key.
  • All three providers state that data sent via an API key is not used to train their models by default.
  • Google Analytics (gtag.js) is loaded on this page and receives anonymous page-view statistics — never your document, keys, or results.
  • This tool stores nothing: no database, no file writes, no logs of your document or keys.
